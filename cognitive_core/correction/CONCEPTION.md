# Correction — Conception

A correction is a warranted refinement intended to improve future behavior while preserving unaffected valid structure.

The current target is asymmetric:

```text
maximize future performance gain
while minimizing unjustified collateral change
```

CLPR asks whether representation geometry can make relevant corrections local and trajectory-predictive. Issue #44 asks when a validated correction is authorized to become persistent state.

These are separate questions:

```text
correction expressibility ≠ correction authority
```
