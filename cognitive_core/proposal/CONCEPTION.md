# Proposal — Conception

A proposal is a candidate change to the cognitive core's model, policy, representation, or action plan.

```text
K_t --evidence--> K'_t
```

`K'_t` is not automatically authoritative. Proposal generation must remain distinct from evaluation, validation, authorization, and persistence.

```text
proposal ≠ correction ≠ authorized commit
```

The proposal layer is expected to evolve substantially as CEA acquires empirical results about search, representation, counterfactuals, and regime switching.
